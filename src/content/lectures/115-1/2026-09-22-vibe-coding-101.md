🚀 軟體開發首要必學工具：VS Code
寫程式的第一步，不是背語法，而是先學會你的武器！
VS Code 看起來只是一個「打程式的軟體」，但從建立專案、寫下第一行程式，到執行、除錯、Git 版本控制，甚至讓 AI 幫你寫 Code，一個 VS Code 就能搞定你的整套開發流程！
這堂課將帶你從零認識 VS Code，實際打造自己的開發環境，從建立第一個專案、編輯程式碼，到使用 Terminal、Git 與 AI 助理，一步步解鎖程式開發的必備技能。
不管你是第一次碰 VS Code，還是每次開啟 VS Code 都只會對著滿滿的按鈕發呆——
這堂課，帶你從「會開」進化到「真的會用」！
🔥 準備好你的鍵盤，來打造你的第一個程式開發基地吧！
