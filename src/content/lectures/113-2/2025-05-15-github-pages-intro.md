藉由前幾堂課所學的 Git 基礎指令與 HTML/CSS 網頁開發技巧，本次課程將帶領大家整合所學並進一步探索 GitHub 平台。我們將介紹如何運用 GitHub Pages 服務來架設靜態網站，同時也會深入講解 Git 在多人協作專案中的應用場景。透過實際操作，讓社員能更全面地掌握以 Git 為核心的版本控制技術，並學會如何運用 GitHub 平台來展示自己的作品。
