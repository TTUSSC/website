延續上週的社課教導社員使用版本控制系統，這次我們將介紹線上版本控制平台 GitHub，讓大家學習如何透過 Git 與 GitHub 進行多人協作。課程中將帶領大家註冊 GitHub 帳號、建立專案倉庫，並實際操作如何將本地的程式碼推送到 GitHub 上，以及如何與他人共同開發專案。透過這堂課，你將學會如何運用版本控制系統進行團隊合作開發。
