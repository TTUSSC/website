Java 作為一種廣泛應用的程式語言，在後端開發、行動應用與企業級系統等等領域占有重要地位。不管是第一次接觸程式設計或已經學會其他程式語言，Java 都是一個值得學習的程式語言。本次課程將介紹 Java 的開發基礎，從開發環境開始，逐步學習變數宣告、資料型態、條件判斷、方法等核心概念。
