Python 作為當今最受歡迎的程式語言之一，憑藉其簡潔的語法與強大的功能，在數據分析、人工智慧、網頁開發、自動化處理等領域佔有重要地位。本次課程，希望能讓社員們在短時間內掌握 Python 的基礎語法，從開發環境開始，逐步學習變數宣告、資料型態、輸入輸出、數學運算、條件判斷等核心概念，並透過實際的問題練習來強化理解，此外還會比較 C語言 和 Python 的語法差別，讓大家加深對 Python 簡潔語法的印象。
