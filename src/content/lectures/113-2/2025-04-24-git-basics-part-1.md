Git 是在不論是開源或是工程師在工作中常使用的版本控制工具，用來監督程式碼的開發，也可以變成多人合作的利器。但在大學課堂中，教師並不會教導學生使用，更多的學生甚至都不知道有這樣的工具存在。這堂課將帶領大家認識 Git 的基本概念和常用指令，讓你在未來的開發道路上更加順暢。
