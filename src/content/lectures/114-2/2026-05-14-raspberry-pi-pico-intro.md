玩膩 Arduino 了嗎？換個開發板來試試看吧！這次活動將以 Raspberry Pi Pico 2 WH 代替Arduino，帶領成員嘗試不同於以往的開發體驗。延續先前社團所學的 Python 基礎，進一步應用 Python 於實際硬體操作中，了解微控制器與外部元件進行互動。透過實作示範與操作體驗，拓展對不同開發板與系統架構的認識，作為後續進階學習的起點。
