大家有沒有那種「昨天程式明明是好的，今天改兩行就報銷，然後還忘記昨天改了啥」的經驗？恭喜你，你需要的不是乖乖，而是 Git！這次社課我們再次請到最強的 Denny 學長，帶大家從零開始玩轉這套開發者的「後悔藥」。這一場我們「不插網線」，專注在你自己電腦裡的檔案管理。我們會用最直白的方式，教你怎麼幫程式碼拍快照、怎麼搭乘時光機回到過去。別再讓你的硬碟塞滿垃圾備份檔了，來學 Git，讓你寫 Code 從此變得優雅又強大！
